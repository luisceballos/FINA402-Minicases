💡 How to read this chart: Each point on a curve represents one particular VGT / VHT mix. Moving from right (100 % VGT) to left (100 % VHT), the curve traces every possible split. The leftmost tip of each curve is the minimum-variance portfolio (MVP) — the allocation that minimises risk for that correlation. As ρ decreases, the curve bows further left, showing larger diversification gains. Only the upper half of each curve (above the MVP) is the true efficient frontier; rational investors would never choose a portfolio below the MVP.
